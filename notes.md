Команда pwd показывает то место где ты сейчас находишься
Команда ls -la просматривает все файлы в том месте, где ты сейчас
Команда mkdir -p создает папки
Команда touch создает файлы разного формата
Команда echo записывает текст в файлы текстового формата
Команда cat просматривает файл
Команда cp копирует файл
Команда mv перемещает файл 
Чтобы открыть текстовый редактор нужно ввести команду nano
